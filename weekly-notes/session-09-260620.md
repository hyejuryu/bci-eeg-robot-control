# Session 09

## 1. Objectives

* OpenBCI Cyton board를 EEG acquisition device로 이해한다.
* Cyton의 active channel, SRB2 reference, BIAS, USB dongle, battery power의 역할을 정리한다.
* OpenBCI EEG Headband Kit 기반의 첫 alpha reactivity montage 후보를 작성한다.
* EEG recording 전 필요한 safety / environment checklist를 정리한다.
* Session 10의 OpenBCI GUI 연결 테스트를 위한 go/no-go 기준을 정한다.

## 2. Research question

What hardware, electrode, safety, and environmental conditions must be prepared before testing posterior alpha reactivity with OpenBCI Cyton?

Session 07에서는 public EEG dataset을 이용해 eyes-open / eyes-closed 조건 사이에서 posterior alpha power 차이를 확인했다.

따라서 Session 09의 목표는 새로운 EEG 데이터를 해석하는 것이 아니라, 같은 alpha reactivity sanity check를 OpenBCI Cyton 기반 self-recording으로 수행하기 전에 필요한 장비 구조, 전극 배치 후보, 안전 조건, 측정 환경을 정리하는 것이다.

## 3. What I studied

* OpenBCI Cyton 8-channel board의 기본 구성
* Cyton board의 active EEG input channel 후보:

  * N1P–N8P
* SRB2 reference의 역할
* BIAS의 역할
* USB dongle을 통한 computer communication 구조
* Battery-powered EEG recording의 필요성
* OpenBCI EEG Headband Kit 구성:

  * comb Ag/AgCl electrodes
  * flat Ag/AgCl electrodes
  * earclip cable pair
  * snap cables
  * velcro headband strap
* Headband-based approximate posterior montage 설계
* EEG recording safety checklist
* OpenBCI GUI 연결 전 확인해야 할 recording environment 조건

## 4. Key takeaways

### 1. OpenBCI setup is part of the research method, not just hardware preparation

OpenBCI Cyton setup은 단순한 장비 연결이 아니라, 이후 EEG 데이터를 어떻게 해석할 수 있는지를 결정하는 연구 방법의 일부다.

EEG 데이터가 기록되더라도 다음 정보가 없으면 해석이 어려워진다.

```text
which electrode
→ which scalp/headband position
→ which Cyton channel
→ which reference
→ which BIAS connection
→ which recording condition
```

따라서 Session 09에서는 실제 recording보다 먼저 equipment inventory, board map, montage, safety checklist를 문서화했다.

### 2. EEG channel values are measured relative to a reference electrode

EEG channel은 한 지점의 절대 전압이 아니라, active electrode와 reference electrode 사이의 voltage difference로 기록된다.

현재 이해는 다음과 같다.

```text
EEG channel value
= active electrode voltage - reference electrode voltage
```

이번 setup에서 SRB2는 reference candidate이며, 첫 OpenBCI headband setup에서는 one earclip을 SRB2 reference로 사용하는 것을 후보로 정리했다.

이 measurement-level reference는 PSD 분석 이후 계산하는 beta/alpha ratio 같은 feature-level ratio와 다른 개념이다.

### 3. BIAS is not an EEG measurement channel

BIAS는 active EEG channel로 해석하지 않는다.

현재 이해는 다음과 같다.

```text
active channel
= EEG signal measurement candidate

SRB2 reference
= comparison point for EEG channel measurement

BIAS
= noise-reduction body connection candidate
```

BIAS가 common-mode noise를 실제로 어떤 방식으로 줄이는지는 아직 완전히 이해하지 못했으며, Session 10 이후 OpenBCI GUI hardware setting을 확인하면서 더 정리해야 한다.

### 4. The first montage should be approximate, not overclaimed

이번 setup은 10–20 EEG cap이 아니라 OpenBCI EEG Headband Kit 기반이다.

따라서 전극 위치를 exact O1 / O2 / Oz처럼 표현하지 않고, 다음과 같이 기록하는 것이 더 적절하다.

```text
posterior-left headband position
posterior-right headband position
posterior-midline candidate
```

이 표현은 위치 해석을 과장하지 않으면서도, posterior alpha reactivity sanity check라는 목적에는 충분하다.

### 5. The first GUI test should start simple

처음부터 8 channels를 모두 사용하는 것은 적절하지 않다.

초기 GUI connection test는 다음 구조로 시작하는 것이 더 현실적이다.

```text
2 active posterior channels
+ 1 SRB2 earclip reference
+ 1 BIAS earclip
```

Ch3 posterior-midline candidate는 Ch1 / Ch2가 안정적으로 확인된 뒤 추가하는 것이 적절하다.

### 6. Safety and metadata must be defined before collecting EEG data

OpenBCI EEG recording은 몸에 전극을 연결하는 작업이므로, 실험 전에 safety / environment checklist가 필요하다.

초기 원칙은 다음과 같다.

```text
Cyton battery-powered EEG recording only
No Arduino / robot hardware connected during EEG recording
Short self-recording sessions first
```

또한 recording data만 저장하는 것으로는 부족하다.

각 recording session에서 channel mapping, reference position, BIAS position, condition labels, recording duration, visible noise, discomfort, setup issue 등을 함께 기록해야 나중에 EEG 데이터를 해석할 수 있다.

## 5. My understanding

이번 회차를 통해 public EEG analysis에서 self-recorded EEG acquisition으로 넘어가기 전에 필요한 준비 요소를 정리했다.

Session 07까지는 이미 저장된 EEG dataset을 불러와 다음 흐름으로 분석했다.

```text
public EEG data
→ filtering
→ PSD
→ alpha/beta power
→ condition comparison
```

하지만 OpenBCI self-recording에서는 분석 이전에 다음 흐름이 먼저 필요하다.

```text
electrode
→ snap cable
→ Cyton input / SRB2 / BIAS
→ Cyton board
→ USB dongle
→ OpenBCI GUI
→ recorded file
→ Python analysis
```

즉, 앞으로는 raw EEG file이 자동으로 주어지는 것이 아니라, 직접 recording setup을 구성해야 한다.

이번 회차에서 가장 중요한 이해는 다음과 같다.

```text
data quality begins before data collection
```

전극 위치, reference, BIAS, headband stability, battery power, recording environment, metadata 기록 방식이 모두 이후 PSD와 band power 분석의 해석 가능성에 영향을 준다.

따라서 Session 09는 실제 EEG recording session이 아니라, OpenBCI recording readiness를 확보하는 준비 회차로 정리할 수 있다.

## 6. Questions / unclear points

* BIAS는 실제로 common-mode noise를 어떤 방식으로 줄이는가?
* Reference location이 recorded EEG signal에 어떤 영향을 주는가?
* 첫 alpha reactivity test는 2 active posterior channels로 충분한가, 아니면 3 active posterior channels가 더 적절한가?
* OpenBCI GUI에서 recording 전에 어떤 hardware setting을 확인해야 하는가?

  * channel on/off
  * SRB2
  * BIAS
  * gain
  * impedance
* Headband-based posterior position이 실제 alpha reactivity 확인에 충분히 안정적인가?
* OpenBCI GUI에서 저장되는 raw data format과 이후 Python analysis pipeline은 어떻게 연결되는가?

## 7. Next actions / Go-no-go for Session 10

### Go if

* Equipment inventory is complete.
* Cyton board map is documented.
* Active channel / SRB2 / BIAS candidates are documented.
* Alpha reactivity montage v0.1 is written.
* EEG recording safety and environment checklist is written.
* Windows 11 laptop is ready for OpenBCI GUI installation.

### No-go if

* Battery condition is unclear.
* Reference / BIAS connection is not documented.
* Electrode placement is not documented.
* Arduino, servo motor, or robot hardware is being connected during EEG recording.

### Session 10 direction

Session 10 should focus on OpenBCI GUI installation and connection testing.

Main tasks:

* Install OpenBCI GUI on Windows 11.
* Connect Cyton board and USB dongle.
* Confirm that intended channels appear in the GUI.
* Check real-time EEG waveform.
* Check whether unused channels should be disabled or ignored.
* Confirm recording file location.
* Record screenshots or short screen recording if useful.
