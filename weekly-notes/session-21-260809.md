# Session 21 — Decision-Rule Sensitivity and Temporal Feature Variability

- **Status:** Completed
- **Work dates:** 2026-08-09 to 2026-08-16
- **Subject:** 1
- **Recordings:**
  - Run 1 — baseline eyes open
  - Run 2 — baseline eyes closed
- **Feature:** `posterior_alpha_mean_psd`
- **Primary temporal comparison:** 1 s, 2 s, and 4 s windows with step fixed at 1 s

## 1. Overview

Session 21 examined decision-rule sensitivity and temporal variability in the posterior-alpha feature for Subject 1.

Phase 1A completed the 18-rule threshold–smoothing–dwell grid using the fixed `win-2s_step-1s` feature stream. Phase 1B characterized feature variability using distributional and successive-change metrics across the Session 14 temporal configurations.

Phase 2A followed up three observations from Phase 1: the dependence of original-scale variability measures on feature magnitude, the non-monotonic Run 1 successive-change volatility at the 2 s window, and the representation of a known local feature event relative to the decision threshold and subsequent command states.

The Phase 1 observations and the rationale for the Phase 2A follow-up were recorded separately in `results/session-21/session21_phase1_checkpoint.md`. That checkpoint is retained as an intermediate decision record; this note records the completed Session 21 analysis and its integrated interpretation.

## 2. Objectives and Scope

The objectives were to:

1. characterize threshold, smoothing, and dwell sensitivity across the complete 18-rule decision grid;
2. compare complementary measures of posterior-alpha temporal variability;
3. evaluate magnitude-normalized successive variability;
4. quantify the contribution of a previously identified local feature event to recording-level successive-difference variance; and
5. trace the threshold-relative representation and command propagation of the same event.

Run 1 and Run 2 were analyzed separately.

For window-length comparisons, the primary analysis used a fixed 1 s step. Cross-step values were retained as descriptive records but were not used for direct scientific ranking because the elapsed interval between successive estimates and the degree of outer-window overlap change with step size.

## 3. Analysis and Results

### 3.1 Phase 1A — Decision-Rule Grid

The complete grid contained three thresholds, two smoothing conditions, and three dwell values, for a total of 18 rules.

In Run 1, active switching was concentrated in the EO-Q95 threshold family. With no smoothing, active OPEN↔CLOSE switches decreased from 4 to 2 to 0 as dwell increased from 1 to 2 to 3 updates.

Run 2 showed the corresponding pattern in the EC-Q05 threshold family, with active switches also decreasing from 4 to 2 to 0 across dwell values 1, 2, and 3.

Median-3 smoothing changed feature and evidence sequences in some rule combinations and reduced short switching episodes in selected cases.

The frozen reference rule, `thr-gap-mid__smooth-none__dwell-2`, produced no active OPEN↔CLOSE switches in either recording. Its duration-based command occupancy was:

- Run 1: OPEN `0.95`, STOP `0.05`, CLOSE `0.00`
- Run 2: CLOSE `0.95`, STOP `0.05`, OPEN `0.00`

### 3.2 Phase 1B — Temporal Feature Variability

Three complementary metrics were calculated.

**Relative IQR**

`(Q75 - Q25) / median(x)`

This metric describes distributional spread relative to feature magnitude without using temporal order.

**Spectral-feature volatility**

`SD(Δx)`, where `Δx_t = x_t - x_(t-1)`

This was adapted from the consecutive spectral-power change formulation used by Yu et al. (2024).

**Median absolute successive change**

`median(|Δx|)`

This was used as a project-defined robust summary of typical successive-change magnitude.

For the primary common-step comparison, the results were:

**Relative IQR**

- Run 1: 1 s `0.7896`, 2 s `0.4979`, 4 s `0.5146`
- Run 2: 1 s `0.8437`, 2 s `0.6914`, 4 s `0.5950`

**SD(Δx)**

- Run 1: 1 s `3.03e-11`, 2 s `3.93e-11`, 4 s `1.71e-11 V²/Hz`
- Run 2: 1 s `3.94e-10`, 2 s `2.63e-10`, 4 s `1.06e-10 V²/Hz`

**median(|Δx|)**

- Run 1: 1 s `1.48e-11`, 2 s `8.66e-12`, 4 s `4.03e-12 V²/Hz`
- Run 2: 1 s `2.06e-10`, 2 s `1.87e-10`, 4 s `6.16e-11 V²/Hz`

For Run 2, both successive-change metrics decreased from 1 s to 2 s to 4 s.

For Run 1, `median(|Δx|)` decreased across the same window lengths, whereas `SD(Δx)` increased from 1 s to 2 s and then decreased at 4 s.

### 3.3 Phase 2A-1 — Magnitude-Normalized Variability

At the fixed `win-2s_step-1s` configuration, the median posterior-alpha feature was approximately:

- Run 1: `3.996e-11 V²/Hz`
- Run 2: `5.038e-10 V²/Hz`

The Run 2 median was approximately 12.61 times the Run 1 median.

Two magnitude-normalized measures were therefore calculated.

The primary normalized metric was:

`nMSSD = mean((Δx)^2) / mean(x^2)`

The magnitude-normalization rationale was adapted from Li et al. (2018), who applied normalized MSSD to EEG waveform variability. In Session 21, the formulation was applied instead to the window-level posterior-alpha PSD feature sequence.

A project-defined robust companion was also calculated:

`median(|Δx|) / median(x)`

For the primary common-step comparison:

**nMSSD**

- Run 1: 1 s `0.364`, 2 s `0.542`, 4 s `0.113`
- Run 2: 1 s `0.421`, 2 s `0.189`, 4 s `0.033`

**Normalized median successive change**

- Run 1: 1 s `0.430`, 2 s `0.217`, 4 s `0.095`
- Run 2: 1 s `0.464`, 2 s `0.371`, 4 s `0.117`

The Run 1 2 s condition remained distinct across the two normalized measures: nMSSD increased relative to the 1 s condition, whereas normalized median successive change decreased.

### 3.4 Phase 2A-2 — Local Successive-Difference Variance Contribution

The Run 1 `win-2s_step-1s` feature stream contained 59 feature estimates and 58 successive differences.

The analysis used the 24–26 s local feature event previously identified and decomposed in Session 14.

The two successive changes associated with entering and leaving this event had the largest absolute changes and the largest variance contributions in the recording:

- entering the selected 24–26 s window:
  - `Δx = +1.837e-10`
  - variance contribution: `37.74%`
- leaving the selected window:
  - `Δx = -1.991e-10`
  - variance contribution: `44.11%`

Together, the two changes accounted for `81.84%` of the total centered successive-difference variance.

The reproduced recording-level `SD(Δx)` was `3.93e-11 V²/Hz`.

### 3.5 Phase 2A-3 — Feature-to-Command Event Trace

The same Run 1 24–26 s event was examined using the fixed gap-midpoint threshold.

A continuous threshold-relative margin was calculated as:

`m_t = (y_t - T) / T`

where `y_t` is the processed feature supplied to the threshold classifier and `T` is the midpoint threshold.

At decision time 26 s, the unsmoothed feature produced:

- processed feature: `2.232e-10 V²/Hz`
- threshold-relative margin: `+59.61%`
- evidence: `HIGH_ALPHA`
- HIGH evidence episode: 1 update

The command state at this point was:

- dwell 1: active switch confirmed → `CMD_CLOSE`
- dwell 2: no active switch → `CMD_OPEN`
- dwell 3: no active switch → `CMD_OPEN`

With causal median-3 smoothing at the same decision time:

- processed feature: `3.959e-11 V²/Hz`
- threshold-relative margin: `-71.70%`
- evidence: `LOW_ALPHA`

The command remained `CMD_OPEN` for dwell values 1, 2, and 3.

## 4. Integrated Interpretation

### 4.1 The variability metrics captured distinct properties of the same feature sequence

The metrics used in Session 21 did not represent the same property of variability.

Relative IQR described the relative spread of the feature distribution without temporal ordering. `median(|Δx|)` described the typical magnitude of adjacent changes. `SD(Δx)` described the dispersion of successive changes and was more sensitive to large local deviations because it is derived from squared deviations.

The Run 1 2 s condition demonstrated this distinction directly: its typical successive-change magnitude decreased relative to the 1 s condition, while its `SD(Δx)` increased.

### 4.2 Magnitude normalization changed the between-recording comparison

The original-scale successive-change measures were substantially larger in Run 2, but Run 2 also had a substantially larger posterior-alpha feature magnitude.

After multiplicative scale normalization, the original Run 2 > Run 1 ordering did not persist consistently. The relative ordering depended on window length and on whether squared or median-based successive changes were used.

The original-scale comparison therefore combined feature magnitude and temporal-change structure, whereas the normalized measures provided a separate scale-normalized representation.

### 4.3 Run 1 2 s successive-difference variance was highly concentrated in a known local event

In the Run 1 2 s condition, the two successive changes associated with the previously identified 24–26 s event accounted for `81.84%` of total successive-difference variance.

This showed that the dispersion represented by `SD(Δx)` in this condition was highly concentrated in a small number of local changes rather than distributed uniformly across the recording.

At the same time, `median(|Δx|)` remained a summary of the typical successive-change magnitude and was much less influenced by these two extreme changes.

### 4.4 Threshold-relative excursion and evidence persistence represented distinct properties of the selected event

The threshold-relative margin added information that was not retained by the binary LOW/HIGH evidence state.

For the selected event, the unsmoothed processed feature was `59.61%` above the midpoint threshold, whereas the causal median-3 processed feature was `71.70%` below it. The change in threshold classification was therefore associated with a substantial shift in threshold-relative feature position rather than a small movement near the threshold boundary.

In the unsmoothed stream, however, the `+59.61%` excursion produced HIGH evidence for only one update. It propagated to a CLOSE switch with dwell 1 but was not confirmed with dwell 2 or 3.

The event therefore separated two temporal properties that are collapsed differently by the current decision rule:

- **threshold-relative excursion magnitude:** how far the processed feature lies above or below the threshold;
- **evidence persistence:** how long the resulting categorical evidence state continues.

The current binary classifier retains the sign of the threshold crossing but not its relative magnitude, while dwell confirmation operates on evidence persistence rather than margin magnitude.

## 5. Scope

Session 21 was a single-subject methodological analysis using two baseline recordings.

Run 1 and Run 2 were analyzed separately and were not pooled.

The resulting metric set and interpretation structure can now be evaluated across additional subjects to determine which patterns are consistent across recordings and subjects.
