# Session 07

## 1. Objectives

- EEGBCI public dataset의 baseline eyes open / eyes closed run을 이용해 frequency-domain analysis를 수행한다.
- Subject 1의 Run 1 eyes open, Run 2 eyes closed 데이터를 분석한다.
- Raw EEG signal에 1–40 Hz band-pass filtering을 적용한다.
- Posterior channel을 선택하여 eyes open / eyes closed 조건에서 PSD를 비교한다.
- Welch method를 이용해 power spectral density를 계산한다.
- Alpha band와 beta band power를 계산한다:
  - alpha: 8 Hz ≤ f < 13 Hz
  - beta: 13 Hz ≤ f ≤ 30 Hz
- Eyes closed condition에서 posterior alpha power가 증가하는지 확인한다.
- Alpha/beta power와 beta/alpha ratio를 CSV와 figure로 저장한다.

## 2. Research question

Can posterior alpha power distinguish eyes-closed and eyes-open baseline conditions in a public EEG dataset?

이 질문은 OpenBCI Cyton 8-channel board로 실제 EEG 데이터를 수집하기 전, frequency-domain analysis pipeline이 정상적으로 작동하는지 확인하기 위한 연습 단계의 질문이다.

## 3. What I studied

- EEGBCI dataset의 baseline eyes open / eyes closed run 사용
- MNE `eegbci.load_data()`를 이용한 EEGBCI file loading
- `mne.io.read_raw_edf()`를 이용한 EDF file loading
- Raw EEG signal에 대한 1–40 Hz band-pass filtering
- Posterior channel selection:
  - `Po3.`
  - `Poz.`
  - `Po4.`
  - `O1..`
  - `Oz..`
  - `O2..`
- Welch method를 이용한 PSD 계산
- `compute_psd(method="welch", fmin=1, fmax=40)` 사용
- PSD object의 frequency axis와 power data 확인:
  - `psd.freqs`
  - `psd.get_data()`
- PSD data shape 해석:
  - channels × frequency points
- Posterior channel 평균 PSD 계산
- Eyes open / eyes closed PSD comparison figure 생성
- Alpha/beta frequency band mask 생성
- Alpha power, beta power, beta/alpha ratio 계산
- Condition-level band power summary CSV 저장
- Matplotlib을 이용한 PSD 및 band power visualization

## 4. Key takeaways

### 1. Raw EEG waveform만으로 alpha/beta rhythm을 해석할 수 없다

Session 06에서는 raw EEG waveform을 직접 시각화했다.

하지만 raw waveform만 보고:

```text
alpha가 증가했다
beta가 감소했다
```

같은 해석을 하는 것은 적절하지 않다.

이번 회차에서는 raw EEG를 frequency-domain으로 변환하여 alpha/beta power를 계산했다.

전체 흐름은 다음과 같다.

```text
raw EEG
→ 1–40 Hz band-pass filtering
→ posterior channel selection
→ Welch PSD
→ posterior mean PSD
→ alpha/beta band power
→ eyes open / eyes closed comparison
```

이를 통해 EEG waveform을 보는 것과 EEG rhythm을 분석하는 것은 다른 작업이라는 점을 이해했다.

### 2. PSD는 frequency별 power를 보여주는 representation이다
이번 회차에서 PSD 결과의 shape은 다음과 같았다.

```text
PSD shape: (6, 500)
```

이는 다음을 의미한다.

```text
6 = selected posterior channels
500 = frequency points between approximately 1 Hz and 40 Hz
```

즉, 6개 posterior channel 각각에 대해 500개의 frequency point에서 power가 계산되었다.

이번 분석에서 frequency spacing은 다음과 같았다.

```text
0.078125 Hz
```

이번 회차를 통해 PSD 결과를 해석할 때는 단순히 그래프만 보는 것이 아니라, data shape과 frequency axis를 함께 확인해야 한다는 점을 배웠다.

### 3. Eyes closed condition에서 posterior alpha power가 크게 증가했다

이번 분석에서는 Subject 1의 baseline eyes open / eyes closed 데이터를 사용하였다.

| Item | Value |
|---|---|
| Subject | 1 |
| Run 1 | baseline eyes open |
| Run 2 | baseline eyes closed |
| Sampling frequency | 160 Hz |
| Selected posterior channels | 6 |
| Filtering range | 1–40 Hz |
| PSD method | Welch |
| Alpha band | 8 Hz ≤ f < 13 Hz |
| Beta band | 13 Hz ≤ f ≤ 30 Hz |

Posterior mean PSD comparison figure에서 가장 뚜렷한 차이는 10 Hz 부근에서 나타났다.

Eyes-closed condition에서는 alpha band인 8–13 Hz 범위에서 강한 PSD peak가 나타났다.

반면 eyes-open condition에서는 같은 frequency range의 power가 훨씬 낮았다.

이번 결과는 다음과 같이 요약할 수 있다.

```text
eyes closed → clear posterior alpha peak around 10 Hz
eyes open   → much lower posterior alpha power
```

따라서 이번 Subject 1 데이터에서는 posterior alpha power가 eyes-open condition과 eyes-closed condition을 구분하는 feature로 잘 작동했다.

다만 이 결과를 mental state를 직접 읽은 것으로 해석하면 안 된다. 이번 분석에서 확인한 것은 다음과 같이 제한된다.

```text
정의된 eyes-open / eyes-closed baseline condition 사이에서 posterior alpha-band power가 다르게 나타났다.
```

### 4. Band power 결과는 alpha reactivity를 잘 보여준다

이번 회차에서 계산한 band power summary는 다음과 같다.

| Condition | Alpha power | Beta power | Beta/Alpha ratio |
|---|---:|---:|---:|
| baseline_eyes_open | 4.1429e-11 | 1.2779e-11 | 0.3084 |
| baseline_eyes_closed | 4.7801e-10 | 3.0087e-11 | 0.0629 |

Condition comparison 결과는 다음과 같다.

| Comparison | Value |
|---|---:|
| Alpha power, eyes closed / eyes open | 11.54 |
| Beta power, eyes closed / eyes open | 2.35 |
| Beta/alpha ratio, eyes closed / eyes open | 0.204 |
| Beta/alpha ratio, eyes open / eyes closed | 4.90 |

가장 중요한 결과는 eyes-closed condition에서 posterior alpha power가 eyes-open condition보다 약 11.5배 높았다는 점이다.

Beta power도 eyes-closed condition에서 증가했지만, 증가 폭은 alpha power보다 작았다.

따라서 beta/alpha ratio는 eyes-closed condition에서 더 낮게 나타났다.

### 5. Beta/alpha ratio는 단독으로 해석하면 위험하다

이번 결과에서 beta/alpha ratio는 eyes-closed condition에서 낮아졌다.

하지만 이것은 beta power가 감소했기 때문이 아니다.

이번 결과에서는:

```text
eyes closed alpha power ≈ eyes open alpha power의 11.5배
eyes closed beta power ≈ eyes open beta power의 2.35배
```

즉, alpha power가 beta power보다 훨씬 크게 증가했기 때문에 beta/alpha ratio가 낮아졌다.

따라서 beta/alpha ratio를 사용할 때는 반드시 alpha power와 beta power 원값을 함께 확인해야 한다.

이번 회차에서 beta/alpha ratio는 eyes-closed condition이 alpha-dominant하게 변했다는 보조 지표로 볼 수 있다.

하지만 이 ratio는 alpha-dominance를 보여주는 보조 지표로만 해석해야 하며, 심리 상태를 직접 판정하는 지표로 사용하면 안 된다.

## 5. My understanding

이번 회차 이전에는 PSD와 alpha/beta power가 추상적인 개념에 가까웠다.

하지만 실제 EEGBCI dataset에 적용하면서 다음 관계를 코드 수준에서 연결할 수 있었다.

```text
time-domain EEG signal
→ frequency-domain PSD
→ band-specific power
→ condition-level comparison
```

Session 06에서는 EEG data를 `channels × samples` 구조의 time-series data로 이해했다.

이번 Session 07에서는 같은 EEG data를 frequency-domain에서 다시 보았다.

특히 다음 관계가 중요했다.

```text
psd.freqs
= PSD graph의 x-axis에 해당하는 frequency values

psd.get_data()
= 각 channel과 frequency point에서의 power values
= PSD graph의 y-axis로 사용할 수 있는 값
```

또한 `posterior_mean_psd = psd_data.mean(axis=0)`의 의미도 이해했다.

원래 PSD data는 다음 구조였다.

```text
6 posterior channels × 500 frequency points
```

여기서 `axis=0` 방향으로 평균을 내면, 각 frequency point마다 6개 posterior channel의 power를 평균내게 된다.

그 결과는 다음과 같다.

```text
posterior mean PSD = 500개 frequency point를 가진 1차원 array
```

이번 회차를 통해 EEG analysis에서 중요한 것은 단순히 “그래프가 나왔다”가 아니라, 다음을 함께 확인하는 것임을 알게 되었다.

```text
data shape
frequency axis
frequency spacing
selected channels
band definition
condition comparison
interpretation boundary
```

또한 beta/alpha ratio 같은 feature를 사용할 때는 반드시 원값을 함께 확인해야 한다는 점도 이해했다.

Ratio feature는 편리하지만, ratio 변화의 원인이 beta 변화인지 alpha 변화인지, 또는 둘 모두인지 분해해서 봐야 한다.

## 6. Questions / unclear points

- Welch PSD에서 `n_fft`, `n_per_seg`, `n_overlap`을 명시적으로 설정하면 frequency spacing과 PSD shape은 어떻게 달라지는가?
- 이번 결과가 posterior channel 선택에 얼마나 민감한가?
  - O1, Oz, O2만 사용해도 같은 alpha peak가 나타나는가?
  - PO3, POz, PO4까지 포함했을 때와 결과가 얼마나 다른가?
- Alpha power를 평균 PSD로 계산하는 방식과 band power를 적분 또는 sum으로 계산하는 방식은 결과 해석에서 어떤 차이를 만드는가?
- Eyes closed alpha reactivity는 subject마다 얼마나 달라지는가?
- 실제 OpenBCI data에서도 같은 수준의 posterior alpha peak를 관찰할 수 있을까?
- Later focus/task condition에서는 beta/alpha ratio가 어떤 방식으로 해석되어야 할까?
- Feature를 threshold rule로 사용하려면 single value comparison이 아니라 window-based distribution을 어떻게 확인해야 할까?
